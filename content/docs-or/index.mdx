odiaui ହେଉଛି [shadcn ରେଜିଷ୍ଟ୍ରି ପ୍ରୋଟୋକଲ](https://ui.shadcn.com/docs/registry)
ଉପରେ ନିର୍ମିତ ଏକ କମ୍ପୋନେଣ୍ଟ ରେଜିଷ୍ଟ୍ରି। କମ୍ପୋନେଣ୍ଟଗୁଡ଼ିକ ସୋର୍ସ କୋଡ୍ ଭାବରେ ଆପଣଙ୍କ
ପ୍ରୋଜେକ୍ଟକୁ କପି ହୁଏ — ତାହା ଆପଣଙ୍କର, ଏବଂ ଆପଣ ଇଚ୍ଛାମୁତାବକ ବଦଳାଇ ପାରିବେ।

## ସ୍ଥାପନ

ରେଜିଷ୍ଟ୍ରିକୁ ଥରେ ଯୋଡ଼ନ୍ତୁ:

<InstallCommand command="shadcn@latest registry add @odiaui=https://odiaui.xyz/r/{name}.json" />

ତାପରେ ଯେକୌଣସି କମ୍ପୋନେଣ୍ଟ ସ୍ଥାପନ କରନ୍ତୁ:

<InstallCommand command="shadcn@latest add @odiaui/button" />

## କାହିଁକି odiaui?

- **କୋଡ୍ ଆପଣଙ୍କର।** କମ୍ପୋନେଣ୍ଟଗୁଡ଼ିକ ଆପଣଙ୍କ ପ୍ରୋଜେକ୍ଟରେ ସାଧାରଣ ଫାଇଲ୍, କୌଣସି
  ରନ୍‌ଟାଇମ୍ ନିର୍ଭରତା ନୁହେଁ।
- **ଥିମ୍ ସହିତ ଖାପ ଖାଏ।** ରଙ୍ଗ shadcn ଟୋକେନ୍ ଏବଂ ସ୍ୱତନ୍ତ୍ର `--odia-*`
  ଭେରିଏବଲ୍‌ରୁ ଆସେ, ତେଣୁ ଲାଇଟ୍ ଏବଂ ଡାର୍କ ମୋଡ୍ ସ୍ୱଭାବିକ ଭାବରେ କାମ କରେ।
- **ଏଜେଣ୍ଟ ପାଇଁ ପ୍ରସ୍ତୁତ।** ଡକ୍ସ Markdown ଏବଂ ଏକ
  [MCP ସର୍ଭର](/or/docs/mcp) ଭାବରେ ଉପଲବ୍ଧ, ତେଣୁ ଆସିଷ୍ଟାଣ୍ଟମାନେ ସିଧାସଳଖ
  ପଢ଼ି ପାରିବେ।

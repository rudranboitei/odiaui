odiaui is a component registry built on the
[shadcn registry protocol](https://ui.shadcn.com/docs/registry). Components are
copied into your project as source code that you own and can customize.

## Install

Add the registry once:

```bash
bunx shadcn@latest registry add @odiaui=https://odiaui.xyz/r/{name}.json
```

Then install any component:

```bash
bunx shadcn@latest add @odiaui/button
```

## Why odiaui?

- **You own the code.** Components are plain files in your project, not a
  runtime dependency.
- **Theme-aware.** Colors come from shadcn tokens and self-contained
  `--odia-*` variables, so light and dark mode work out of the box.
- **Made for agents.** The docs ship as Markdown and an
  [MCP server](/docs/mcp), so assistants can read them directly.

<Callout title="Using an AI agent?">
  Point it at [`/llms.txt`](/llms.txt) for an index, or connect the

</Callout>

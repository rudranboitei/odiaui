## Installation

<InstallCommand command="shadcn@latest add @odiaui/avatar" />

The item needs `@radix-ui/react-avatar` and `class-variance-authority`. Its
colours come from self-contained `--odia-*` tokens, so it keeps its look in any
host theme.

Fourteen placeholder portraits install as SVGs into `public/avatars/`, with a
ready-made list in `components/ui/avatar-placeholders.ts`. They are local files
on your own site — no remote URL or image host required. If you replace a
placeholder with your own file, keep the same path so the list keeps working.

## Usage

```tsx
import {
  Avatar,
  AvatarFallback,
  AvatarImage,
} from "@/components/ui/avatar"
import { avatarPlaceholders } from "@/components/ui/avatar-placeholders"

export function Example() {
  const image = avatarPlaceholders[0]

  return (
    <Avatar size="lg">
      <AvatarImage src={image.src} alt={image.label} />
      <AvatarFallback>?</AvatarFallback>
    </Avatar>
  )
}
```

`Avatar` wraps the Radix root. `AvatarImage` takes any local or remote image;
`avatarPlaceholders` gives you local SVGs out of the box. `AvatarFallback`
covers the initial state and any failed image.

## Avatar Group

`AvatarGroup` overlaps avatars and adds a surface-coloured separation ring, so
the stack still reads on a card.

<ComponentPreview>
  <AvatarGroupDemo />
</ComponentPreview>

```tsx
import { Avatar, AvatarGroup } from "@/components/ui/avatar"
import { avatarPlaceholders } from "@/components/ui/avatar-placeholders"

<AvatarGroup role="group" aria-label="OdiaUI team">
  {avatarPlaceholders.slice(0, 4).map((image) => (
    <Avatar key={image.src}>
      <AvatarImage src={image.src} alt={image.label} />
      <AvatarFallback>?</AvatarFallback>
    </Avatar>
  ))}
</AvatarGroup>
```

`public/avatars/`, so `src` is a root-relative path — nothing is fetched from a
third-party URL. `avatarPlaceholders` gives you the paths and alt text in one

## Image

For a real photo, point `AvatarImage` at any image URL. Radix keeps the fallback
visible until the image loads and whenever it fails.

```tsx
<Avatar size="lg">
  <AvatarImage src="/team/maya.jpg" alt="Maya" />
  <AvatarFallback>MK</AvatarFallback>
</Avatar>
```

## API Reference

### Avatar

| Prop        | Type                                | Default     |
| ----------- | ----------------------------------- | ----------- |
| `size`      | `"sm" \| "default" \| "lg" \| "xl"` | `"default"` |
| `className` | `string`                            | —           |

`Avatar` passes every other prop to the Radix root, so `aria-label`, `role` and
data attributes work as usual.

### AvatarImage

Takes the native `<img>` props. Always pass a real `alt`.

### AvatarFallback

Takes the native props of the Radix fallback. Set `delayMs` to hold it back while
an image loads.

### AvatarBadge

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | —       |

Sits at the bottom-right and scales with the avatar. Children render inside it,
so an icon works too.

### AvatarGroup

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | —       |

A flex row with negative spacing. Each direct `Avatar` child gets the separation
ring.

### AvatarGroupCount

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | —       |

Matches the size of the avatars in its group and accepts an icon.

### avatarPlaceholders

A typed, read-only array of `{ src, label }` objects for the 14 installed SVGs.
Use `src` as `AvatarImage`’s `src` and `label` as its `alt`. The files live at
`public/avatars/<name>.svg`; no prop is required.

`className` merges last through `cn` on every component part, so you can
override any style.

## Accessibility

- Every placeholder label describes its artwork. Use it as `AvatarImage`’s
  `alt`, or pass a person's name when the avatar represents someone.
- `AvatarFallback` initials are read as-is. If they are cryptic, put an
  `aria-label` on the `Avatar` instead.
- The overflow count needs context: label the `AvatarGroup` with `role="group"`,
  an `aria-label`, and a count that reads well on its own.
- Decorative icons inside `AvatarBadge` and `AvatarGroupCount` are
  `aria-hidden`. Never rely on the badge colour alone to convey status.

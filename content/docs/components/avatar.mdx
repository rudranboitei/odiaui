## Installation

<InstallCommand command="shadcn@latest add @odiaui/avatar" />

The item needs `@radix-ui/react-avatar` and `class-variance-authority`. Its
colours come from self-contained `--odia-*` tokens, so it keeps its look in any
host theme.

The ten illustrated portraits ship inside the item as inline SVG
(`components/ui/avatar-art.tsx`), so they need no image files. Fourteen extra
placeholder portraits are installed as SVGs into `public/avatars/`, with a
ready-made list in `components/ui/avatar-placeholders.ts`. They are local files
on your own site — no remote URL or image host required. If you replace a
placeholder with your own file, keep the same path so the list keeps working.

## Usage

```tsx
import { Avatar } from "@/components/ui/avatar"
import { AvatarArt } from "@/components/ui/avatar-art"

export function Example() {
  return (
    <Avatar>
      <AvatarArt name="odissi-dancer" />
    </Avatar>
  )
}
```

`Avatar` wraps the Radix root. `AvatarArt` fills it with one of the built-in
portraits; `AvatarImage` and `AvatarFallback` handle real photos and initials.

## Composition

```text
Avatar
├── AvatarImage
├── AvatarArt
├── AvatarFallback
└── AvatarBadge

AvatarGroup
├── Avatar
└── AvatarGroupCount
```

## Image

For a real photo, use `AvatarImage`. Radix keeps the fallback visible until the
image loads and whenever it fails.

```tsx
import {
  Avatar,
  AvatarFallback,
  AvatarImage,
} from "@/components/ui/avatar"

<Avatar size="lg">
  <AvatarImage src="/team/maya.jpg" alt="Maya" />
  <AvatarFallback>MK</AvatarFallback>
</Avatar>
```

## Placeholder Images

Fourteen flat placeholder portraits come with the item. The SVGs install into
`public/avatars/`, so `src` is a local, root-relative path — nothing is fetched
from a third-party URL and nothing breaks if you deploy under your own domain.
`avatarPlaceholders` gives you the paths and alt text in one typed list.

<ComponentPreview>
  <AvatarImageDemo />
</ComponentPreview>

```tsx
import {
  Avatar,
  AvatarFallback,
  AvatarImage,
} from "@/components/ui/avatar"
import { avatarPlaceholders } from "@/components/ui/avatar-placeholders"

export function Example() {
  const placeholder = avatarPlaceholders[0]

  return (
    <Avatar size="lg">
      <AvatarImage src={placeholder.src} alt={placeholder.label} />
      <AvatarFallback>?</AvatarFallback>
    </Avatar>

}
```

## API Reference

### Avatar

| Prop        | Type                                | Default     |
| ----------- | ----------------------------------- | ----------- |
| `size`      | `"sm" \| "default" \| "lg" \| "xl"` | `"default"` |
| `className` | `string`                            | —           |

`Avatar` passes every other prop to the Radix root, so `aria-label`, `role` and
data attributes work as usual.

### AvatarImage

Takes the native `<img>` props. Always pass a real `alt`.

### AvatarFallback

Takes the native props of the Radix fallback. Set `delayMs` to hold it back while
an image loads.

### AvatarBadge

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | —       |

Sits at the bottom-right and scales with the avatar. Children render inside it,
so an icon works too.

### AvatarGroup

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | —       |

A flex row with negative spacing. Each direct `Avatar` child gets the separation
ring.

### AvatarGroupCount

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | —       |

Matches the size of the avatars in its group and accepts an icon.

### AvatarArt

| Prop        | Type            | Default                       |
| ----------- | --------------- | ----------------------------- |
| `name`      | `AvatarArtName` | — (required)                  |
| `label`     | `string`        | a description of the portrait |
| `className` | `string`        | —                             |

`AvatarArtName` is the union of the ten names in the table above. `AvatarArt`
also accepts native `<svg>` props, so `aria-hidden` works for decorative use.

`className` merges last through `cn` on every part, so you can override any
style.

### avatarPlaceholders

A typed, read-only array of `{ src, label }` objects for the 14 installed SVGs.
Use `src` as `AvatarImage`’s `src` and `label` as its `alt`. The files live at
`public/avatars/<name>.svg`; no prop is required.

## Accessibility

- Every portrait has a default label such as “Odissi dancer”. Pass `label` to
  give the actual person's name, or `aria-hidden` when nearby text already does.
- `AvatarFallback` initials are read as-is. If they are cryptic, put an
  `aria-label` on the `Avatar` instead.
- The overflow count needs context: label the `AvatarGroup` with `role="group"`,
  an `aria-label`, and a count that reads well on its own.
- Decorative icons inside `AvatarBadge` and `AvatarGroupCount` are
  `aria-hidden`. Never rely on the badge colour alone to convey status.

## Installation

```bash
bunx shadcn@latest add @odiaui/input
```

The field uses `class-variance-authority` and the shared `cn` utility from
`@/lib/utils`. Its colors come from self-contained `--odia-*` tokens, so it
looks the same in any host theme. Pair it with
[`@odiaui/label`](/docs/components/label) for accessible labels.

## Usage

```tsx
import { Input } from "@/components/ui/input"

export function Example() {
  return <Input type="email" placeholder="Email" />
}
```

### With Label

Always pair a field with a label so screen readers announce its purpose.

<ComponentPreview>
  <InputWithLabelDemo />
</ComponentPreview>

```tsx
import { Input } from "@/components/ui/input"
import { Label } from "@/components/ui/label"

export function InputWithLabel() {
  return (
    <div className="grid w-full max-w-sm gap-2">
      <Label htmlFor="email">Email</Label>
      <Input id="email" type="email" placeholder="m@example.com" />
    </div>
  )
}
```

### Invalid

Set `aria-invalid` to switch the border and focus ring to the error color.
Pair it with a message so the error is not conveyed by color alone.

<ComponentPreview>
  <InputInvalidDemo />
</ComponentPreview>

```tsx
import { Input } from "@/components/ui/input"
import { Label } from "@/components/ui/label"

export function InputInvalid() {
  return (
    <div className="grid w-full max-w-sm gap-2">
      <Label htmlFor="email-invalid">Email</Label>
      <Input
        id="email-invalid"
        type="email"
        aria-invalid
        defaultValue="not-an-email"
      />
      <p className="text-sm text-destructive">
        Enter a valid email address.
      </p>
    </div>
  )
}
```


| `size`      | Height | Text size |
| ----------- | ------ | --------- |
| `"sm"`      | `h-9`  | `text-xs` |
| `"default"` | `h-10` | `text-sm` |
| `"lg"`      | `h-12` | `text-base` |

## API Reference

### Input

`Input` accepts the standard HTML input props, along with the following
component prop.

| Prop        | Type                              | Default     | Description                             |
| ----------- | --------------------------------- | ----------- | --------------------------------------- |
| `size`      | `"default" \| "sm" \| "lg"`       | `"default"` | Sets the field height and text size     |
| `type`      | `string`                          | `"text"`    | Native input type                       |
| `className` | `string`                          | —           | Adds or overrides field styles          |

The native numeric `size` attribute is replaced by the visual `size` prop.
Refs are forwarded and `className` merges last through `cn`.

## Accessibility

- Give every input a visible `<Label htmlFor>` or an `aria-label`.
- Use `aria-invalid` with a text message; never rely on color alone.
- The focus ring is always visible and has a themed offset.
- Disabled fields use the native `disabled` prop and never take focus.

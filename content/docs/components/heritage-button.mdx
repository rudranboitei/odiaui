## Props

| Prop         | Type                                    | Default     | Description                                    |
| ------------ | --------------------------------------- | ----------- | ---------------------------------------------- |
| `variant`    | `"default" \| "outline"`                 | `"default"` | Visual style of the button.                    |
| `size`       | `"sm" \| "default" \| "lg" \| "icon"`   | `"default"` | Height and padding of the button.              |
| `showChakra` | `boolean`                               | `true`      | Show the chakra-inspired decorative icon.      |

Extends all native `<button>` HTML attributes and forwards refs.

> For icon-only buttons, pass `size="icon"` and provide an `aria-label` for accessibility.

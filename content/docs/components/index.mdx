## Conventions

- Colors come from shadcn theme tokens (`primary`, `muted`, `border`, …) and
  self-contained `--odia-*` tokens, so components work in light and dark mode.
- `className` merges last through `cn`, so you can override any style.
- Refs are forwarded, and every component accepts the matching HTML props.

<Callout>
  Building something custom? Start from a shadcn/ui component and apply the
  [design rules](/docs/design) so it matches the rest of the registry.
</Callout>

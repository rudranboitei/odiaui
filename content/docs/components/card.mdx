## Installation

<InstallCommand command="shadcn@latest add @odiaui/card" />

The item needs `class-variance-authority` and installs the `badge` registry item
(it supplies the decorative `BadgeIcon` watermarks). The sand palette is scoped
to the card parts, so no custom theme or global CSS edit is required.

The examples below use the shared `Button`, `Input`, and `Label` components.
Install the [`@odiaui/button`](/docs/components/button#installation),
[`@odiaui/input`](/docs/components/input#installation), and
[`@odiaui/label`](/docs/components/label#installation) items, then import them
from `@/components/ui/button`, `@/components/ui/input`, and
`@/components/ui/label`.

## Usage

```tsx
import {
  Card,
  CardAction,
  CardContent,
  CardDescription,
  CardFooter,

  CardTitle,

```

## Size

Use `size="sm"` for tighter spacing. The size sets the shared `--card-spacing`
variable used by the header, content and footer insets.

<ComponentPreview>
  <CardSizeDemo />
</ComponentPreview>

```tsx
<Card size="sm">
  <CardHeader>
    <CardTitle>Scheduled reports</CardTitle>
    <CardDescription>Weekly snapshots. No more manual exports.</CardDescription>
  </CardHeader>
  {/* ... */}
</Card>
```

| `size`      | `--card-spacing` |
| ----------- | ---------------- |
| `"default"` | `1.5rem`         |
| `"sm"`      | `1rem`           |

## Spacing

For finer control, set `--card-spacing` on the `Card` with an arbitrary property
or an inline style. Every inset follows it.

<ComponentPreview>
  <CardSpacingDemo />
</ComponentPreview>

```tsx
<Card className="[--card-spacing:--spacing(8)]">...</Card>
```

Use negative margins with `-mx-(--card-spacing)` to make content go edge to edge
while staying aligned with the card inset. When edge-to-edge content sits above
a footer, add `-mb-(--card-spacing)` to `CardContent` to remove the section gap.

<ComponentPreview>
  <CardEdgeToEdge />
</ComponentPreview>

```tsx
import { Button } from "@/components/ui/button"
import {
  Card,
  CardContent,
  CardDescription,
  CardFooter,
  CardHeader,
  CardTitle,
} from "@/components/ui/card"

export function CardEdgeToEdge() {
  return (
    <Card className="mx-auto w-full max-w-sm">
      <CardHeader>
        <CardTitle>Terms of Service</CardTitle>
        <CardDescription>
          Review the terms before accepting the agreement.
        </CardDescription>
      </CardHeader>
      <CardContent className="-mb-(--card-spacing)">
        <div
          tabIndex={0}
          aria-label="Terms of Service"
          className="-mx-(--card-spacing) max-h-48 space-y-4 overflow-y-scroll border-t bg-muted/50 px-(--card-spacing) py-4 text-sm leading-relaxed"
        >
          <p>
            These terms govern your use of the workspace, including access to
            shared documents, project files, and collaboration tools.
          </p>
          <p>
            You are responsible for the content you upload and for ensuring that
            your team has the appropriate permissions to view or edit it.
          </p>
          <p>
            We may update features or limits as the service evolves. When those
            changes materially affect your workflow, we will notify your
            workspace administrators.
          </p>
          <p>
            By continuing, you agree to keep your account credentials secure and
            to follow your organization&apos;s acceptable use policies.
          </p>
        </div>
      </CardContent>
      <CardFooter className="justify-end gap-2">
        <Button variant="outline">Decline</Button>
        <Button>Accept</Button>
      </CardFooter>
    </Card>
  )
}
```

The scrollable terms region is focusable (`tabIndex={0}`) with an `aria-label`, so
keyboard users can scroll it and screen readers can identify it.

## Image

Add an image before the header to create a card with a cover. The negative top
margin cancels the card's top padding so the image bleeds to the edges.

<ComponentPreview>
  <CardImageDemo />
</ComponentPreview>

```tsx
<Card size="sm">
  <img
    src="/cover.jpg"
    alt="Event cover"
    className="-mt-(--card-spacing) aspect-video w-full rounded-t-[inherit] object-cover"
  />
  <CardHeader>
    <Badge variant="secondary" className="w-fit">Featured</Badge>
    <CardTitle>Design systems meetup</CardTitle>
  </CardHeader>
  <CardFooter>
    <Button className="w-full">View Event</Button>
  </CardFooter>
</Card>
```

`CardMedia` is the OdiaUI shortcut for this: `<CardMedia position="top">`
applies the same edge bleed and a sand fallback background. It also supports
`position="bottom"` and `position="left"`.

## Watermarks

The `watermark` prop prints faint Odisha artwork into the corner of a card. It is
off by default, decorative only (`aria-hidden`), and never sits on top of the
content, so a card stays readable at any size.

<ComponentPreview className="p-6">
  <CardWatermarksDemo />
</ComponentPreview>

```tsx
<Card watermark="chakra">
  <CardHeader>
    <CardTitle>Chakra</CardTitle>
    <CardDescription>The sixteen-spoke wheel carved at Konark.</CardDescription>
  </CardHeader>
</Card>
```

| Value      | Motif                |
| ---------- | -------------------- |
| `"none"`   | No artwork (default) |
| `"deula"`  | Kalinga temple tower |
| `"chakra"` | Konark wheel         |
| `"padma"`  | Lotus                |

The motif sits fully inside the bottom-right corner and scales with the card's
width, so it reads as a print on the paper instead of artwork clipped by the
border. That keeps it intact on `size="sm"` cards and on tall ones alike.

## Ornament

`CardOrnament` is a thin ikat diamond strip. Drop it between sections as a
divider — a negative inline margin lets it bleed to the card edges.

```tsx
<CardContent className="py-0">
  <CardOrnament className="-mx-(--card-spacing) h-3" />
</CardContent>
```

## API Reference

### Card

| Prop        | Type                                       | Default     |
| ----------- | ------------------------------------------ | ----------- |
| `size`      | `"default" \| "sm"`                        | `"default"` |
| `watermark` | `"none" \| "deula" \| "chakra" \| "padma"` | `"none"`    |
| `className` | `string`                                   | —           |

Every part (`CardHeader`, `CardTitle`, `CardDescription`, `CardAction`,
`CardContent`, `CardFooter`) takes the native props of the `div` it renders.
`className` is merged last through `cn`, and refs pass through as regular props
(React 19).

## Accessibility

- Watermarks and the ikat strip are decorative (`aria-hidden="true"`) and never
  take focus. Give a real `<img>` its own `alt` text.
- Interactive content such as `Button` keeps its own focus ring, labels and
  reduced-motion behavior.

```bash
bunx shadcn@latest add @odiaui/skeleton
```

## Usage

```tsx
import { Skeleton } from "@/components/ui/skeleton"

export function Example() {
  return <Skeleton className="h-4 w-48" />
}
```

## Variants

- **`heritage`** (default) — warm sandstone tint with a faint jali lattice, inspired by Odisha temple stone screens.
- **`plain`** — neutral `bg-muted` surface for generic layouts.


## Accessibility

`Skeleton` is decorative and renders with `aria-hidden="true"`. For screen-reader
users, wrap your loading region in a live status container:

```tsx
<div role="status" aria-live="polite">
  <span className="sr-only">Loading content…</span>
  <Skeleton className="h-4 w-48" />
</div>
```

The pulse animation is disabled automatically for users who prefer reduced motion
(`motion-reduce:animate-none`).

## Shapes

Heritage silhouettes carry their own carved artwork and set their own aspect
ratio — size them with `className`.

<ComponentPreview className="p-6">
  <SkeletonShapes />
</ComponentPreview>

| Shape     | Placeholder                            |
| --------- | -------------------------------------- |
| `none`    | Free-form block (default)              |
| `line`    | Thin text line, `h-2.5 w-full`         |
| `chakra`  | Konark wheel — square                  |
| `arch`    | Deula doorway arch — 3:4               |
| `diamond` | Diamond-cut square (clip-path)         |
| `pida`    | Stepped pidha roof block               |

```tsx
<Skeleton shape="chakra" className="size-14" />
<Skeleton shape="arch" className="h-16 w-12" />
<Skeleton shape="diamond" className="size-11" />
<Skeleton shape="pida" className="h-11 w-28" />
```

## Variants

<ComponentPreview className="p-6">
  <SkeletonVariants />
</ComponentPreview>

- **`default`** — classic pulse on a soft foreground tint.
- **`shimmer`** — a background sheen pulsing over the surface.
- **`ikat`** — an ikat band of dashes and outlined diamonds, tiled along the shape.

## Artwork

Add one artwork or an array to a media placeholder. Combined layers are ordered
sky → gateway → temple, so temples always read in front.

<ComponentPreview className="p-6">
  <SkeletonArtGrid />
</ComponentPreview>

| Art      | Placement                                            |
| -------- | ---------------------------------------------------- |
| `temple` | Kalinga rekha deula skyline along the bottom         |
| `wheel`  | Konark wheel cropped into the top-right corner       |
| `arch`   | Nested doorway arch standing at the bottom centre    |

```tsx
<Skeleton art="temple" className="aspect-[16/9] w-full" />
<Skeleton art={["temple", "wheel"]} className="aspect-video w-full" />
```

## Props

| Prop      | Type                                                             | Default     | Description                    |
| --------- | ---------------------------------------------------------------- | ----------- | ------------------------------ |
| `variant` | `"default" \| "shimmer" \| "ikat"`                                | `"default"` | Animated surface treatment.    |
| `shape`   | `"none" \| "line" \| "chakra" \| "arch" \| "diamond" \| "pida"`   | `"none"`    | Silhouette plus its artwork.   |
| `art`     | `"temple" \| "wheel" \| "arch"` or an array                       | —           | Artwork for media placeholders.|

Extends all native `<div>` attributes and forwards refs.

## Accessibility

`Skeleton` is decorative and renders with `aria-hidden="true"`. Announce loading
state on a wrapper instead:

```tsx
<div role="status" aria-live="polite">
  <span className="sr-only">Loading content…</span>
  <Skeleton shape="line" className="w-48" />
</div>
```

Animation is disabled automatically for users who prefer reduced motion
(`motion-reduce:animate-none`).

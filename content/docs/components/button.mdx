## Installation

This version includes a built-in loading state on top of the standard
shadcn-style variants. Installing through the registry pulls in
`class-variance-authority`, `@radix-ui/react-slot`, and `lucide-react` and wires
up the `cn` utility from `@/lib/utils` automatically.

<InstallCommand command="shadcn@latest add @odiaui/button" />

## Usage

```tsx
import { Button } from "@/components/ui/button"

export function Example() {
  return <Button>Click me</Button>
}
```

### Spinner

Set `isLoading` to display a spinner and disable the button. Use `loadingText`
to show different text while the action is in progress.

<ComponentPreview>
  <ButtonSpinnerDemo />
</ComponentPreview>

```tsx
"use client"

import * as React from "react"
import { Button } from "@/components/ui/button"

export function LoadingButton() {
  const [isLoading, setIsLoading] = React.useState(false)

  function handleAction() {
    setIsLoading(true)

    setTimeout(() => {
      setIsLoading(false)
    }, 1500)
  }

  return (
    <Button
      isLoading={isLoading}
      loadingText="Downloading..."
      onClick={handleAction}
    >
      Download on the App Store
    </Button>
  )
}
```

When `isLoading` is `true`, the button displays a spinner and becomes disabled.
If `loadingText` is not provided, the button keeps its original children beside
the spinner.

### As Link

Use `asChild` to apply the button’s styles to its child element. This is useful
when rendering a button-styled link.

<ComponentPreview>
  <ButtonAsLinkDemo />
</ComponentPreview>

```tsx
import Link from "next/link"
import { Button } from "@/components/ui/button"

export function LinkButton() {
  return (
    <Button asChild>
      <Link href="/dashboard">Go to dashboard</Link>
    </Button>
  )
}
```

## API Reference

### Button

`Button` accepts the standard HTML button props, along with the following
component props.

| Prop          | Type                                                                          | Default     | Description                                      |
| ------------- | ----------------------------------------------------------------------------- | ----------- | ------------------------------------------------ |
| `variant`     | `"default" \| "secondary" \| "outline" \| "ghost" \| "destructive" \| "link"` | `"default"` | Sets the visual style                            |
| `size`        | `"default" \| "sm" \| "lg" \| "icon"`                                         | `"default"` | Sets the button size                             |
| `asChild`     | `boolean`                                                                     | `false`     | Renders the styles on the child using Radix Slot |
| `isLoading`   | `boolean`                                                                     | `false`     | Shows the spinner and disables the button        |
| `loadingText` | `string`                                                                      | —           | Replaces the button content while loading         |
| `disabled`    | `boolean`                                                                     | `false`     | Disables the button                              |
| `className`   | `string`                                                                      | —           | Adds or overrides button styles                  |

### buttonVariants

`buttonVariants` is the exported `class-variance-authority` function for
generating button classes.

```tsx
import { buttonVariants } from "@/components/ui/button"

const className = buttonVariants({
  variant: "outline",
  size: "sm",
})
```

## Accessibility

- Use descriptive text for buttons so their purpose is clear.
- Give icon-only buttons an accessible name with `aria-label`.
- Use `disabled` or `isLoading` to prevent interaction while an action is
  unavailable or in progress.

`isLoading` keeps the button disabled while an action runs so it cannot be
triggered twice. The spinner and disabled state do not rely on color alone to
communicate the change.

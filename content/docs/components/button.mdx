## Installation

```bash
bunx shadcn@latest add @odiaui/button
```

## Usage

```tsx
import { Button } from "@/components/ui/button"

export function Example() {
  return <Button>Click me</Button>
}
```

This is the single shared button used by every OdiaUI component. It uses the
OdiaUI blue `#3b82f6` with a chakra mark by default; set `showChakra={false}` or
use `variant="outline"` for a quieter action.

## Variants

<ComponentPreview>
  <ButtonDemo />
</ComponentPreview>

```tsx
<Button variant="default">Default</Button>
<Button variant="outline">Outline</Button>
<Button showChakra={false}>No Chakra</Button>
```

| Variant     | Appearance                                                   |
| ----------- | ------------------------------------------------------------ |
| `default`   | `#3b82f6` fill, blue edge, dark ink text                     |
| `outline`   | Transparent, blue border and text (dark-mode aware)          |

## Props

| Prop         | Type                                  | Default     | Description                               |
| ------------ | ------------------------------------- | ----------- | ----------------------------------------- |
| `variant`    | `"default" \| "outline"`              | `"default"` | Visual style.                             |
| `size`       | `"sm" \| "default" \| "lg" \| "icon"` | `"default"` | Height and padding.                       |
| `showChakra` | `boolean`                             | `true`      | Show the chakra-inspired decorative icon. |

Extends all native `<button>` attributes and forwards refs. `className` is
merged last, so you can override any style.

## Accessibility

- Renders a real `<button>` with a visible `#3b82f6` focus ring and a themed offset.
- The dark ink label (`#020617`) reaches **5.48:1** on the `#3b82f6` fill (WCAG
  AA); white would only reach 3.68:1. The outline text uses a darker blue in
  light mode and a lighter blue in dark mode.
- The chakra mark is decorative (`aria-hidden="true"`) and never takes focus.
- Disabled buttons use `disabled:pointer-events-none disabled:opacity-50`.
- Icon-only buttons (`size="icon"`) need an `aria-label`.
- The scale-down press effect is disabled under reduced-motion preferences.

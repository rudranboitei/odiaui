## Prerequisites

You need a project with [shadcn/ui](https://ui.shadcn.com) already configured.
If you haven't set up shadcn yet, run the init command:

<InstallCommand command="shadcn@latest init" />

## Add the registry

<Steps>
<Step>

**Register the namespace**

Add `@odiaui` to your `components.json` once. This is the recommended way to
install components.

<InstallCommand command="shadcn@latest registry add @odiaui=https://odiaui.xyz/r/{name}.json" />

</Step>
<Step>

**Install a component**

<InstallCommand command="shadcn@latest add @odiaui/button" />

The component is copied into `components/ui`, along with the dependencies and
`--odia-*` CSS variables it needs.

</Step>
<Step>

**Use it**

```tsx
import { Button } from "@/components/ui/button"

export function Example() {
  return <Button>Click me</Button>
}
```

</Step>
</Steps>

## Install by URL

If you don't want to register the namespace, pass the item URL directly:

<InstallCommand command="shadcn@latest add https://odiaui.xyz/r/button.json" />

## Browse the registry

List every available item:

<InstallCommand command="shadcn@latest list @odiaui" />

Or open the [components overview](/docs/components).

<Callout title="Package manager">
  Every command above supports Bun, npm, pnpm, and Yarn — switch tabs to match
  the package manager your project uses.
</Callout>
